# Medication Reminder App

## Description
This is a C# Windows Forms application that helps users keep track of their medications and remember when to take them. Users can add medications, view reminder times, and mark medications as taken with optional notes.

## Features
- Add medications with an ID, name, dosage, frequency, and dates.
- Set up reminders based on the selected frequency.
- Get reminder popups when medication is due.
- Mark medications as taken and save a note in the log.
- Validate information entered by the user.

## How to Run
Open the project in Visual Studio, build the solution, and run the application. Enter the medication information and click the Add button to create reminders.

## Notes
The reminders use short time intervals for demonstration and testing. Medication information and logs are stored in memory, so they are cleared when the application closes.

## Testing
I tested adding medications, correcting invalid entries, and marking medications as taken.
